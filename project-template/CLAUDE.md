# Claude Code Project Instructions

Read and follow `AGENTS.md` as the primary development workflow and project rules.

Before any medium or large implementation:

1. Read the relevant project documentation under `docs/`.
2. Investigate existing implementation before proposing changes.
3. Create or update the relevant feature specification.
4. Propose the implementation plan before coding.
5. Reuse existing or proven solutions before writing custom infrastructure.
6. Validate against acceptance criteria after implementation.
